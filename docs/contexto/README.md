# Contexto do projeto

Memória compartilhada entre pessoas e agentes de IA. **Leia no começo de toda tarefa e
atualize no fim** (skill `atualizar-contexto`). Quem chega depois só sabe o que está escrito aqui.

| Arquivo | Para que serve | Quando atualizar |
|---|---|---|
| [VISAO_GERAL.md](VISAO_GERAL.md) | o que é o app, para quem, princípios | raramente |
| [ARQUITETURA.md](ARQUITETURA.md) | como as partes funcionam e conversam | ao mudar fluxo, arquivo central ou formato de dado |
| [ESTADO_ATUAL.md](ESTADO_ATUAL.md) | o que está pronto, em andamento, problemas e ideias | **em toda tarefa** |
| [DECISOES.md](DECISOES.md) | decisões tomadas e o porquê | ao decidir algo que não é óbvio pelo código |
| [GLOSSARIO.md](GLOSSARIO.md) | termos do AVA, Q-Acadêmico e do código | ao surgir termo novo |

Regras: português, frases curtas, sem dados pessoais (nomes reais, matrículas, notas,
tokens). Datas absolutas (`2026-11-14`), nunca "ontem" ou "semana que vem".
