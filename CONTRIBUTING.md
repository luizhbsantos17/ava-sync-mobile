# Como enviar sugestões e problemas

Use as opções **Relatar um problema** e **Sugerir uma melhoria** na aba Issues
do GitHub. Não publique senha, token do Moodle, dados pessoais, notas ou imagens
com informações privadas.

Quem receber apenas a permissão **Read** pode consultar o código e abrir Issues,
mas não pode enviar alterações diretamente para este repositório. Uma pessoa que
queira propor código pode trabalhar em um fork e abrir um pull request. O pull
request fica separado da branch principal até o proprietário revisar e aceitar.

Antes de convidar alguém para um repositório privado, conceda somente **Read**.
Não use Write ou Maintain para quem só precisa ler o código e reportar problemas.
Para reforçar que a branch principal só muda após revisão, habilite nas regras do
GitHub a exigência de pull request e bloqueie pushes diretos para `main`.
